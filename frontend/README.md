# Multimodal Customer Service Agent frontend

这是一个 React + TypeScript 客服运营工作台。项目页面和组件位于
`src/aka`，共享 UI 基础包含基于 RAGFlow 改造的代码。

## Development

```bash
npm ci
npm run dev
```

## Checks

```bash
npm test -- --runInBand
npm run type-check
npm run build
```

For the default full-stack setup, run `../run_dev.sh` from the repository root.
